> **Masala Café & Boutique Hotels** is a luxury hospitality web experience showcasing authentic culinary heritage alongside luxury heritage stays. From artisanal dining to tranquil boutique accommodations, it offers guests an immersive journey into flavor and comfort.

---

## 🌟 Key Features

- **🍽️ Handcrafted Culinary Menu**:
  - Curated selections across traditional Indian heritage recipes, global fusion, artisanal coffees, and specialty desserts.
  - Interactive categorization with pricing, chef recommendations, and dietary tags.
- **🏰 Luxury Boutique Stays**:
  - Detailed suite showcases featuring high-resolution photography, architectural charm, and modern luxury inclusions.
- **📅 Dual Booking & Reservation Engine**:
  - **Table Reservations**: Select date, time slot, party size, dining ambiance (Terrace, Indoor Lounge, Private Dining), and special requests.
  - **Hotel Stay Booking**: Effortlessly choose check-in/out dates, guest rooms, and custom stay packages.
- **✨ Curated Experiences**: Highlights of live acoustic sessions, heritage high tea, masterclasses with executive chefs, and private banquet hosting.
- **🎨 Premium Visual Design**: Warm earthy tones, bespoke typography, smooth scroll animations, and responsive layout across mobile and desktop.

---

## 🛠️ Tech Stack

- **Structure**: Semantic HTML5
- **Design & Layout**: CSS3 (Modern Flexbox & Grid, CSS Custom Properties, Elegant Transitions & Animations)
- **Client Logic**: Vanilla JavaScript (Interactive Menus, Reservation Form Validation, Booking Flow)

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/omkalmegh4-gif/cafe.git
cd cafe
```

### 2. Launch
Open `index.html` in your favorite web browser, or serve it locally:
```bash
# Using Python
python -m http.server 8080
```
